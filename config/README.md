# RG 配置示例

本目录的 `gateway.example.toml` 是远端网关的配置草案，**当前程序不会读取、校验或应用该文件**。其中地址、接口和端口均为示例值，不应直接用于现网。

后续配置需要明确：

- LG 的域名与连接端口，以及经可信渠道核验的连接身份。
- RG 的互联网出口与目标网络出口；两者可能使用不同网卡。
- 获准访问的单个目标地址、来源和协议端口。
- 地址转换与返回路径，以及变更前的检查和恢复方式。

RG 计划主动连接 LG，无须固定公网 IP；LG 的连接入口必须实际可达。RG 将在本机独立执行访问限制，LG 的请求不能自行扩大 RG 已批准的范围。

配置中不要填写或提交真实密码、私钥等敏感信息。Web 管理和配置应用功能仍待实现。

参见 [项目说明](../README.md) 和 [Web 管理规划](../docs/web-management.md)。
