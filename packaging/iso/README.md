# RG ISO 安装介质规划

**尚未实现安装器或 ISO 生成器，目前没有可引导安装介质。** CLI 验证包不是系统安装镜像。

系统基线为裁剪后的 Debian 13（trixie）。首期计划提供 x86_64 UEFI 安装介质；aarch64 是系统架构目标，但其安装介质须针对具体启动环境验证，不承诺通用 ISO。

安装流程计划包含：

- 清楚显示目标磁盘和数据清除影响，确认后再执行安装。
- 配置 RG 的网络出口及 LG 连接地址。
- 为每台设备生成独立身份与随机初始密码。
- 提供默认 Web 用户 `admin`，首次登录强制改密后重新登录。
- 安装后自动提供本机管理入口，并保留配置和账号的恢复能力。

RG 计划主动连接 LG，无须固定公网 IP。Web、网关转发、自启和上述安装流程均尚未实现。

嵌入式设备需要逐板验证启动、驱动与刷写方式，板级磁盘镜像不能由通用 ISO 代替。

参见 [项目说明](../../README.md)、[虚拟机镜像](../vm/README.md) 和 [Web 管理规划](../../docs/web-management.md)。
