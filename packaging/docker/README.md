# RG Docker 交付

**当前 Docker 镜像只封装 CLI 验证程序，提供帮助和版本信息，尚不能作为网关部署。** Web 管理、连接建立、网络转发和自动恢复均待实现。

基础镜像为 `debian:trixie-slim`，对应裁剪后的 Debian 13（trixie）。架构目标为 `linux/amd64` 与 `linux/arm64`，分别对应 x86_64 和 aarch64。

后续完整交付需要验证：

- RG 主动连接 LG，无须 RG 拥有固定公网 IP。
- 目标与协议授权在 RG 本机执行，并正确处理目标网络出口和回程。
- 管理页面独立运行，设备重启后恢复可管理状态。
- 配置、密钥和账号资料随容器更新保留。

计划默认 Web 用户为 `admin`，每台设备独立生成随机初始密码，首次登录必须改密后重新登录；当前镜像没有该登录功能。

容器使用宿主内核，不能替代嵌入式设备的驱动和网络能力验证。每种板型仍需确认宿主运行条件与实际资源用量，目前没有已验证的最低内存承诺。

参见 [项目说明](../../README.md)、[Web 管理规划](../../docs/web-management.md) 和 [自动启动状态](../systemd/README.md)。
