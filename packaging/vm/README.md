# RG 虚拟机镜像规划

**尚未实现镜像生成器，也未提供经过引导验证的虚拟机镜像。**

系统基线为裁剪后的 Debian 13（trixie），计划面向 x86_64 和 aarch64 提供 `qcow2`、`raw` 磁盘镜像。交付前需要验证启动、磁盘扩容、网卡识别、重启恢复与更新恢复。

安装后的 RG 计划主动连接 LG，不要求固定公网 IP，并在本机限制目标与协议、处理目标网络出口及回程。

Web 管理计划随设备启动，LG 离线时仍可本机登录。默认 Web 用户计划为 `admin`，每台设备独立生成随机初始密码，首次登录必须改密并重新登录；当前这些能力尚未实现。

嵌入式板卡需要逐型号验证启动方式、内核和驱动。通用虚拟机镜像不等于 SD/eMMC 刷写镜像，同架构也不代表板卡已经兼容。

参见 [项目说明](../../README.md)、[Web 管理规划](../../docs/web-management.md) 和 [ISO 安装介质](../iso/README.md)。
