# RG Web 管理规划

**当前尚未实现管理页面、登录服务或开机自动启动。现有 CLI 只显示帮助和版本信息。**

RG 将提供独立的远端网关管理页面，用于管理与 LG 的连接、目标服务和本机访问授权。RG 与 LG 的管理账号分别维护，登录 LG 不等于取得 RG 的管理权限。

## 计划中的页面

| 页面 | 用户可查看或执行的操作 |
| --- | --- |
| 总览 | 查看 LG 连接、目标服务、授权和故障状态 |
| LG 连接 | 设置 LG 地址，核验连接身份，查看重连原因 |
| 目标与授权 | 登记目标地址与允许的来源、协议和端口，由本机管理员批准 |
| 网络出口 | 分别检查到 LG 和目标服务的路径，查看地址转换及回程状态 |
| 变更记录 | 预览变更，检查结果，确认应用或恢复上一可用配置 |
| 诊断与账号 | 查看故障证据，导出脱敏诊断资料，管理本机管理员和只读账号 |

页面将区分“未检查”“失败”和“已验证”；RG 能访问目标服务，不代表其他设备已完成整条访问路径验证。

## 默认账号与首次登录

计划默认用户名为 `admin`。每台设备独立生成随机初始密码，通过本设备的受控标签、可信控制台或受保护文件交付，不提供统一通用密码。

首次密码验证成功后只能修改密码或退出，不能进入其他管理功能。改密成功后须使用新密码重新登录，旧密码与旧会话失效。默认用户只用于 Web 管理，不是系统或 SSH 用户。

账号和改密结果应在重启、升级及容器更新后保留；恢复临时密码后也须再次改密。账号资料损坏时应进入恢复流程，不能自动恢复初始密码。这些流程尚待实现。

## 使用流程与访问边界

1. 从设备本机或已有可信管理连接进入登录页面，完成首次改密并重新登录。
2. 核验 LG 身份，设置 LG 地址，由 RG 主动建立连接。
3. 登记允许访问的目标及授权范围，检查互联网与目标网络两个出口。
4. 预览变更并检查结果，在确认期限内决定是否保留；未确认的变更应进入恢复流程。

扩大访问范围必须由 RG 本机管理员批准；LG 离线不应阻止 RG 收回本机授权。管理入口计划默认仅允许本机访问，经已有管理连接转发使用，不直接开放到公网。

## 自动启动与故障体验

最终管理页面计划随设备启动，无须用户先登录系统启动程序。LG 离线或互联网故障时仍应能够登录和改密；正常登录后可查看本机故障信息。

管理页面重启不应中断已生效的网关连接。网络管理服务不可用时应保留安全登录和故障提示，并禁止提交网络变更；不能把重试或重启显示成恢复成功。
