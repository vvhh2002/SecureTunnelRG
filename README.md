# SecureTunnelRG

SecureTunnelRG 是面向嵌入式主机和虚拟机的远端网关项目，计划主动连接 [SecureTunnelLG 本地网关](https://github.com/vvhh2002/SecureTunnelLG)，让获准的设备访问远端目标服务。RG 无须固定公网 IP，仍需能够访问 LG 的连接入口。

**目前处于开发阶段：现有 CLI 只提供帮助和版本信息。Web 管理、隧道转发、自动启动及完整安装镜像均尚未实现。**

## 运行与交付范围

系统基线为裁剪后的 **Debian 13（trixie）**，首期架构目标为 **x86_64 / aarch64**。嵌入式设备的启动方式、网卡驱动与资源用量须逐型号验证，支持同一 CPU 架构不代表所有板卡均可运行。

| 交付形式 | 当前状态 |
| --- | --- |
| CLI 验证包 | 仅用于检查帮助和版本，不提供网关服务 |
| Docker | 可封装 CLI 验证程序，尚不是可部署的网关镜像 |
| 虚拟机镜像 | 规划中，尚未实现镜像生成与引导验证 |
| ISO 安装介质 | 规划中，尚无可引导安装介质 |
| 板级系统镜像 | 需逐型号适配，尚未提供通用刷写镜像 |

## 计划中的功能

- 主动连接 LG，并在断线后恢复连接；连接身份变化时提示管理员核验。
- 在 RG 本机独立限制目标地址、来源和协议，扩大访问范围须由 RG 管理员批准。
- 在目标网络出口处理地址转换与回程，让目标设备无须安装代理或修改默认网关。
- 提供独立 Web 管理，查看连接、目标服务、授权、故障和变更结果。
- 管理页面随设备启动；LG 离线时仍可本机登录。以上功能均待实现和验证。

计划默认 Web 用户为 `admin`，每台设备独立生成随机初始密码；首次登录必须改密，成功后使用新密码重新登录。当前尚无可登录的 Web 服务。
